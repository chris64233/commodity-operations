# commodity-operations

用于管理大宗商品合同、库存批次、物流作业与结算资料的后端服务。

## 暂定价、点价与最终结算

核心代码位于 `src/main/java/com/chris64233/commodityoperations/pricing/`。

### 业务规则

- 合同登记时记录商品、买卖方向、合同数量、计价币种、暂定价格、点价窗口和允许引用的市场价格来源，并立即按暂定价形成暂定结算（应收/应付由方向决定）。
- 所有数量、价格、金额均使用 `BigDecimal` 精确表示，金额保留两位小数（HALF_UP），不使用浮点运算。
- 一次点价可覆盖部分未点价数量，固定市场价格版本、升贴水和点价时间；点价 = 市场价格 + 升贴水。累计点价数量不得超过合同数量。
- 每次点价追加一条 `ADJUSTMENT` 结算版本，只调整本次数量的价差（点价 − 暂定价）× 数量，历史条目不被覆盖。
- 全部数量点价完成后才能生成 `FINAL` 最终结算，最终金额 = 暂定金额 + 累计调整；重复调用返回同一最终结算。
- 幂等：同一合同下相同外部点价号重复提交相同内容返回原结果；数量、价格版本或升贴水变化返回 409 冲突。
- 市场价格过期、币种不符、来源不允许或超出点价窗口时拒绝（422），合同余额不变；最终结算后拒绝迟到点价。
- 并发：合同级悲观锁（`PESSIMISTIC_WRITE`）串行化点价与最终结算，并发点价只消耗仍未点价的数量，最终结算与迟到点价并发时只有一个明确结果。

### API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/contracts` | 登记合同并生成暂定结算 |
| POST | `/api/market-prices` | 登记市场价格（来源/商品/币种/版本/有效期） |
| POST | `/api/contracts/{id}/fixings` | 点价（外部点价号幂等） |
| POST | `/api/contracts/{id}/final-settlement` | 生成最终结算（幂等） |
| GET | `/api/contracts/{id}` | 查询未点价数量、价格快照、暂定金额、累计调整与最终金额 |
