# commodity-operations

用于管理大宗商品合同、库存批次、物流作业与结算资料的后端服务。

## 开发环境

- JDK 21
- Spring Boot 4.1.1
- Maven Wrapper 3.9.9
- H2

## 常用命令

运行测试：

    ./mvnw clean test

启动服务：

    ./mvnw spring-boot:run

## 现货合同分批交货与数量容差

合同登记商品、基础数量、短装比例、溢装比例、交货期限和计量单位，
据此计算允许区间 `[基础数量 × (1 - 短装比例), 基础数量 × (1 + 溢装比例)]`。

### 接口

- `POST /api/contracts` 创建合同
- `POST /api/contracts/{id}/deliveries` 登记交货（外部单号幂等：相同内容重放返回原记录，修改数量/交货时间等返回 409）
- `POST /api/contracts/{id}/deliveries/{deliveryId}/reversals` 追加冲销记录（原记录保留，冲销数量为负）
- `POST /api/contracts/{id}/close` 申请关闭合同
- `GET /api/contracts/{id}` 查询基础数量、容差区间、累计交货、可继续接收数量、冲销与关闭历史

### 规则

- 交货按合同行悲观锁串行化入账，累计数量不得超过溢装上限；商品或计量单位与合同不一致的交货不能混入。
- 并发交货只按尚可接收数量入账；交货时间不得晚于合同交货期限。
- 累计数量达到最低可接受数量后才允许关闭；关闭与新交货并发时只有一个先成功，
  合同关闭后迟到交货拒绝入账，交货先入账时关闭按新的累计数量重新判断。
- 错误交货只能追加冲销记录，不能删除原记录；冲销后累计数量跌出允许区间时，
  已关闭合同转为 `PENDING_REVIEW`，原关闭记录保留并标记 `superseded`。

### 合同状态变化

```
OPEN --(累计数量进入容差区间, 申请关闭)--> CLOSED
CLOSED --(冲销导致累计数量跌出容差区间)--> PENDING_REVIEW
```

- `OPEN`：可继续登记交货、可申请关闭。
- `CLOSED`：不再接收新交货；区间内冲销不改变状态。
- `PENDING_REVIEW`：已关闭合同因冲销跌出容差区间，等待人工复核，关闭历史保留。
